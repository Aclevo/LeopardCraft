# CLAUDE.md

The project instructions for AI coding agents live in [AGENTS.md](AGENTS.md).
Read it before changing code: it contains the architecture map, task recipes,
verification gate and MCP workflow.

Multi-agent work is organized into six lanes. Start with
[`docs/agents/README.md`](docs/agents/README.md) for the playbook and the lane
brief it links. Project subagent definitions in `.claude/agents/` map one-to-one
onto those lanes and load the same briefs.
