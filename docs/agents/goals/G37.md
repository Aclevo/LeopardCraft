**Status:** partially complete — Clone, the triangulation split modes, the
island-aware Fill Hole with its border-click tool, and the documented Scalpel
core with its chained click tool (start → cut → chain → ESC, per source 43) have
landed. Open: viewport-click invocation for the polygon tools that still act

**Tracker:** `TODO.md` §6b (Scalpel core and chained cuts checked).

## Definition of done

- Scalpel and Clone exist with shared predicates, menu/panel entries and undo.
- Triangulation offers a split-direction option beyond the first-corner fan.
- Fill Hole/Cover handle holes that enclose an island.
- Polygon tools can be invoked from a viewport click instead of only the
  current component selection.
- All lane checks and the full gate pass.
