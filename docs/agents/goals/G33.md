# Goal G33 — Wave 33: channel addresses and sampled evaluation

**Status:** complete (2026-11-24).
**Tracker:** `TODO.md` §1 (channel address, grouped channels, scratch sampling).
**Depends on:** G32.
**Roadmap:** [ROADMAP.md](ROADMAP.md).

## Definition of done

- Animation keys address target + property + component instead of a flat
  `AnimProperty` enum; old files deserialize through a compatibility path.
- The registry remains the single source of channel scope and component count.
- Evaluation samples each channel once per frame into a scratch buffer.
- The F-curve row list groups channels by target object.
- All lane checks and the full gate pass.

## Outcome

- `AnimationTrack` stores a `ChannelAddress { target, channel, component }`
  instead of an `AnimProperty`. `ChannelTarget` is `Owner`, `Object { id }`,
  `Tag { node, index }` or `Material { id }`; `ChannelAddress::new` checks the
  component against the registry's declared scalar count, so a fourth
  translation component or a scalar rotation component is refused.
- `AnimChannel` stayed the single registry and gained
  `scalar_component_count`, `component_suffix`, `component_label` and
  `component_default`; `scalar_properties`/`from_scalar_property` were removed.
- Old files load through a custom `AnimationTrack`/`AnimationClip`
  `Deserialize`: snake_case `property` names become owner addresses, and the
  three legacy Euler rotation curves move into
  `AnimationClip::legacy_euler_rotation`, which is preserved on save and still
  sampled in degrees. `key_times`, `retime_all`, `is_empty` and `signature`
  cover that field.
- Evaluation builds a `ChannelSamples` buffer once per clip per frame
  (`sample_channels`). It samples each addressed curve once and resolves
  components through `scalar_for(owner, channel, component)`/`rotation(owner)`,
  where an explicit target wins over an owner-relative address. Node, tag and
  material consumers read from the buffer; the two constraint passes reuse the
  same node/tag buffers.
- Editor recordings write explicit target addresses (`Object`, `Tag`,
  `Material`); rows expose the same addresses and resolve existing
  owner-relative tracks when reading, so old and new clips edit consistently.
  The F-curve list draws a group header per target and shows keyed channels for
  the other targets; clicking a row focuses that target.
- glTF export resolves a node's components through `track_for` and the
  rotation track's target, maps them to TRS paths, and reports channels with no
  glTF path through `animation_export_report`, which names each skipped
  channel in an `AnimationExportReport`.
- Tests: registry/address validation, legacy JSON and on-disk fixture loading,
  sample-once determinism and target isolation, addressed native round-trip and
  signature stability, grouped rows and filters, and glTF skip reporting.
