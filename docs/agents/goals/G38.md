# Goal G38 — Wave 38: rigging constraints

**Status:** complete (2026-11-24). Guide-curve Spline IK, `IkChain.stiffness`
and the IK Point/Angle/Orient/Parent constraint tags are implemented and
serialized with serde defaults, enforced for point, pole and spline chains,
exposed in the Joint inspector and Tags section, baked by **Bake IK take**, and
covered by stiffness, tag-effect, determinism, legacy-JSON and bake tests; the
full gate passes.
**Tracker:** `TODO.md` §2b (all boxes checked).
**Depends on:** G32 for takes and bake framing.
**Roadmap:** [ROADMAP.md](ROADMAP.md).

## Definition of done

- Spline IK curves can drive a joint chain with a documented clean-room
  semantics and bake into the active take.
- IK Angle/Point/Orient/Parent constraints exist as tags with evaluation,
  inspectors, serialization and undo.
- Stiffness and limit behavior are explicit, finite and deterministic.
- README and the parity matrix record which behaviours are documented
  Cheetah3D semantics and which are LeopardCraft approximations.
- All lane checks and the full gate pass.
