## Definition of done

- glTF `skins` become `Skin` data and `animations` become take/key data with
  STEP, LINEAR and CUBICSPLINE interpolation and duration-to-fps conversion.
- Malformed accessors and out-of-range joints fail with a message naming the
  node or accessor.
- The skipped-data summary appears before the scene is replaced and can cancel.
- Skin/animation round-trip tests pass in both directions.
- All lane checks and the full gate pass.
