# Goal G34 — Wave 34: UV authoring suite

**Status:** complete (2026-11-24).
**Tracker:** `TODO.md` §3 (all seven unchecked boxes).
**Depends on:** none for single-set work; the multi-UV-set contract must land
before its editor and interchange consumers.
**Roadmap:** [ROADMAP.md](ROADMAP.md).

## Definition of done

- Seams and pins are authorable in the UV view.
- Charts can be selected, moved, rotated, scaled and packed with controls.
- UV editing operations and multiple UV sets exist and serialise safely.
- A UV checker overlay and distortion readout make unwrap quality visible.
- Single-set and multi-set round-trip tests cover OBJ/glTF and native files.
- All lane checks and the full gate pass.

## Outcome

- **Geometry** (`lc-geom`): `uv_chart_indices`/`uv_charts` derive the same
  seams-and-normal-angle charts unwrap uses; `charts_for_uv_slots` and
  `uv_island_slots` map a point selection to its chart. `transform_uv_charts`
  moves/rotates/scales selected charts. `pack_uv_charts` shelf-packs with
  padding, optional 90° chart rotation and bottom-left/top-left/centre
  alignment, and leaves pinned charts untouched (`UvPackReport` counts them).
  `weld_uv_slots`, `split_uv_slots`, `align_uv_slots`, `distribute_uv_slots`,
  `flip_uv_slots` and `rotate_uv_slots` edit UVs only; weld/split compact or
  extend every set and remap pins. `uv_face_distortion`/
  `uv_distortion_stats` report normalized per-face stretch. `Mesh::extra_uvs`
  stores additional parallel sets with add/remove/read/write helpers; all three
  subdivision schemes carry extra sets by subdividing each set as UV0.
- **Document** (`lc-scene`): `extra_uvs` has a serde default and legacy files
  load as one UV0 set. `repair_mesh` truncates/zero-pads damaged sets and
  sanitizes non-finite coordinates. `Mesh::signature` and `validate` include the
  sets. Native round-trip, short-set repair and stripped-legacy loading are
  tested.
- **Editor** (`lc-ui`): `UvEditorState` holds multi-point selection, active set,
  checker/distortion toggles, chart/pack values and numeric entry as view state.
  The UV view selects with shift/command-click plus Select All/None/Island,
  authors seams (Toggle/All/Loop/Clear), toggles pins for the whole selection and
  drags every selected point. Chart Transform and Pack Charts expose the packing
  controls. The slot operations, numeric entry, Add/Remove UV Set and a
  UV0/UV1/… selector are in the panel; `Tools -> UV Editing` mirrors the
  commands with the same predicate and refusal messages. Every document edit is
  one `SetShapesCmd` undo step; checker, distortion, selection, active set and
  target values never enter history. Projections author the active set; Unwrap,
  Relax and Normalize stay UV0-only and refuse otherwise.
- **Interchange** (`lc-io`): glTF/GLB exports extra sets as `TEXCOORD_1`… and
  imports every `TEXCOORD_n` back as parallel sets; OBJ writes UV0 and records
  `# skipped N additional UV set(s)` when the document has more. GLB and OBJ
  tests cover both paths.
- **Docs**: README UV controls and limitations, `TODO.md` §3 (all authoring
  boxes), the parity matrix row and a new parity section, and the geometry/
  document/editor/interchange lane briefs were updated.
- **Follow-up closed**: the texture/lightmap UV-set binding landed after this
  mission. `ShaderNodeKind::Texture` now carries a UV set index, the renderer
  interpolates every set into `Hit`, and the shaded context samples the chosen
  set (falling back to UV0 for a missing one); see TODO.md §3.

                 and packing padding/rotation/alignment are deterministic and
                 preserve pinned slots. UV operations cover island selection,

                 schema.
