# Goal G39 — Wave 39: MCP automation expansion

**Status:** partially complete — the modifier, material-graph, animation and
mesh/UV authoring tools, the Streamable HTTP transport with its
`Mcp-Session-Id` sessions, resource subscriptions and prompt templates have
landed, and live-editor attachment is implemented: `lc-mcp/src/bridge.rs` serves
the loopback endpoint, the token registry and the attach client,
`lc-ui/src/live.rs` hosts it on the editor's UI thread, and `--attach` routes
tools, undo, resources and selection to the live session. Headless tests cover
the protocol, trust, routing, selection and undo. The toggle is confirmed present
in a running editor; open: one attach run against a live session.
**Tracker:** `TODO.md` §7 (live attachment implemented, live-window check open).
**Depends on:** G38 for rigging/constraint authoring and the modifier/channel
APIs from G33 and G36.
**Roadmap:** [ROADMAP.md](ROADMAP.md).

## Definition of done

- The MCP server can attach to a running editor session and operate on its live
  document and selection.
- Modifier-stack, material-graph, animation and mesh/UV/component authoring
  tools exist with undo, validation and inventory/docs updates.
- Streamable HTTP transport, resource subscriptions and prompt templates are
  implemented behind explicit opt-in and offline defaults.
- The real-process smoke test and the full gate pass.
