## Integrator notes

The Morphs tab is presentation only: it reads each mesh's `MorphSet` and derives
`On` from a positive target weight, so no copy of document state exists and
there is no second weight editor. Playback setters live in `LeopardCraftApp`
and keep the timeline Range menu, the F-curve header and the Animation menu on
one finite, ordered clamp; they never enter history or change the document
signature.
