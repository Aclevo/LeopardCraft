## Integrator notes

The morph rebase is a clean-room choice: Cheetah3D documents a Base/rest
workflow but not what happens to target poses when the base is re-recorded.
LeopardCraft keeps each target's absolute posed shape, which is the closest
equivalent to Cheetah3D storing target poses as absolute vertices. The spot
icon is browser chrome only; light behaviour is untouched.
